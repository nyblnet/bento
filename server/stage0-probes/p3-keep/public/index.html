Does a key kept in this browser survive?

Sittings A6, D2, E4 and F (the week). Make keys creates two keys that can never be exported (a P-256 signing key and a P-256 key-agreement key) and keeps them in this browser's storage for this site. The page never makes a key on its own: when the keys are gone it says no key. Nothing is sent anywhere; the fingerprint is computed here.

Steps

Start (A6, D2, E4): in each browser, as a tab, press Make keys and
Ask to keep, then Copy results. Then the installed form: Safari → File →
Add to Dock (Mac), Share → Add to Home Screen (iPhone), menu → Install app
(Android Chrome); open it from there and do the same. Firefox: note whether it
asked you.


Check-ins (F): open this page in the same browser and mode and Copy
results. Do not press Make keys. Day 3 (Chrome only): after the check-in, clear
History only, reopen, Copy results again. Last, as the positive control: press
Delete my key, reload; it must say "no key".
