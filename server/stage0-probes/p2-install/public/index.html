Open, edit and save a file as an installed app

Sittings A5, E2, E3 and G2. This page opens an HTML file on this device, adds one comment line to it and writes it back. Nothing is uploaded; the page talks to no server but its own host. Use a throwaway copy of a deck: the edit appends <!-- stage-0 probe P2 edit … --> to the end of the file.

Steps

A5 (Mac Chrome) / G2 (Windows): 1. Open a file, Edit and save. 2. Reload: note the permission prompt's choices, pick "Allow on every visit". 3. Install the app (address bar → Install) and repeat 1–2 inside it. 4. Finder (Explorer) → right-click the deck → Open With: is "Probe P2" listed? Open with it, Edit and save, then check the file on disk changed (the comment is at its end; Finder's Date Modified changes). Screenshot each prompt.

E2 (Android): 1. Open a file (which picker?), Edit and save; is the file in Files changed? 2. Reload: does the stored file reconnect, and with what prompt? 3. Install (menu → Install app). Files → long-press the deck → Open with / Share: is the app offered? Open it there, Edit and save.

E3 (Android, offline share): with the app installed and opened once online, turn on aeroplane mode, then Files → share the deck to the app. The page notes whether the shared file arrived while offline.
