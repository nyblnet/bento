## How to agree

On a pull request that changes `server/directory/`, post this comment, from
the GitHub account the commits are authored under:

> I have read the Bento Individual Contributor License Agreement in
> `server/directory/CLA.md` and I agree to it.

One agreement covers all Your later Contributions to `server/directory/`. A
pull request that changes `server/directory/` cannot be merged until its
author has agreed.
