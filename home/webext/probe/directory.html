Does one directory grant cover every file inside it — across sessions?

This is the premise the whole extension approach rests on. If a stored directory handle re-grants with one click and then hands out writable file handles with no further prompts, a Bento host can save any deck in your Decks folder — including one you opened by double-clicking, which no web page can ever do. If it prompts per file, the idea is worth much less.

Pick a scratch folder. Step 3 creates bento-probe.txt inside it and writes a line to it. Nothing else is touched, and it tells you before it writes.
Step 1. Grant a folder, once.
Step 2. Reload this page (⌘R). The handle is read back from IndexedDB and its state is reported without prompting.
Step 3. Re-grant with one click, then write a file inside the folder — the file itself was never picked.
