Does a Bento document survive an opaque origin?

The only isolation left to bento/home is running a document in <iframe sandbox="allow-scripts"> — no allow-same-origin, so it reaches no storage at all, home's or any other document's. The question is what that costs the document.

Nothing is written to disk. The file is read into memory and loaded twice: once without the sandbox (the control, so we can tell what the sandbox breaks from what breaks anyway) and once with it.

control — same origin, full storage
sandboxed — opaque origin, no storage
